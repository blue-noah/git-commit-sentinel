git-commit-sentinel

A git commit-msg hook that validates Conventional Commits.

Go · stdlib only · off / warn / error per rule

Install

macOS / Linux 
curl -fsSL https://raw.githubusercontent.com/blue-noah/git-commit-sentinel/main/scripts/install.sh | sh
Windows (PowerShell) 
irm https://raw.githubusercontent.com/blue-noah/git-commit-sentinel/main/scripts/install.ps1 | iex

No Go toolchain, no sudo/admin required. Then run git-commit-sentinel setup — installs globally by default, every repo on the machine. Requires git ≥ 2.9.0.

On every commit

$ git commit -m "fixed a bug"
git-commit-sentinel: error: [format] header "fixed a bug" does not match
the expected format: <type>(<scope>)!: <description>

commit rejected — fix the errors above, or adjust a rule's level with:
  git config --global commitsentinel.rules.<rule> off|warn|error

Rules

RuleDefaultChecks
formaterrorheader matches <type>(<scope>)!: <description>
typeerrortype is in commitsentinel.types
description-emptyerrordescription is not empty
description-periodwarndescription doesn't end with .
header-lengthwarnheader ≤ headerMaxLength (100)
body-blank-linewarnblank line separates header and body

Configure

git config --global commitsentinel.types "feat,fix,docs,chore"
git config --global commitsentinel.rules.<rule> off|warn|error

Diagnose

git-commit-sentinel doctor

Checks git version, PATH, hook status (global + local), effective config.
